# GMCP-R Protocol: Paper Checklist

## Before Submission

### Content

- [ ] **Abstract**: 150-250 words, self-contained
- [ ] **Introduction**: Clear problem statement and contributions
- [ ] **Related Work**: Comprehensive coverage, proper citations
- [ ] **Methodology**: Detailed protocol description
- [ ] **Security Analysis**: Formal security arguments
- [ ] **Experiments**: Complete results with statistical analysis
- [ ] **Conclusion**: Summary and future work

### Writing Quality

- [ ] **Grammar**: No grammatical errors
- [ ] **Clarity**: Clear and concise writing
- [ ] **Consistency**: Consistent terminology
- [ ] **Formatting**: Follow venue guidelines
- [ ] **Citations**: All references properly cited

### Figures and Tables

- [ ] **Resolution**: 600 DPI for raster images
- [ ] **Format**: PDF or EPS for vector graphics
- [ ] **Captions**: Descriptive and self-contained
- [ ] **References**: All figures/tables referenced in text
- [ ] **Quality**: Professional appearance

### Experimental Results

- [ ] **Sample Size**: At least 30 repetitions
- [ ] **Statistical Tests**: t-test, ANOVA, confidence intervals
- [ ] **Error Bars**: Standard deviation or confidence intervals
- [ ] **Baseline Comparison**: Fair comparison with existing work
- [ ] **Reproducibility**: All experiments reproducible

### Security Analysis

- [ ] **Threat Model**: Clearly defined
- [ ] **Security Claims**: Supported by proofs
- [ ] **Attack Scenarios**: Comprehensive coverage
- [ ] **Limitations**: Honestly discussed

### References

- [ ] **Completeness**: All citations complete
- [ ] **Format**: Consistent citation style
- [ ] **Recency**: Include recent work
- [ ] **Relevance**: All references relevant

## LaTeX Specific

### Structure

- [ ] **Sections**: Logical organization
- [ ] **Labels**: All figures, tables, equations labeled
- [ ] **References**: All cross-references resolved
- [ ] **Bibliography**: BibTeX compiled correctly

### Formatting

- [ ] **Page Limit**: Within venue requirements
- [ ] **Font Size**: Follow guidelines
- [ ] **Margins**: Correct margins
- [ ] **Line Spacing**: Appropriate spacing

### Figures

- [ ] **Path**: All figure paths correct
- [ ] **Size**: Appropriate size for column
- [ ] **Resolution**: Meets minimum requirements
- [ ] **Format**: PDF or EPS preferred

## Submission

### Files

- [ ] **Main File**: main.tex
- [ ] **Bibliography**: references.bib
- [ ] **Figures**: All figures included
- [ ] **Supplementary**: If applicable

### Metadata

- [ ] **Title**: Correct and descriptive
- [ ] **Authors**: All authors listed
- [ ] **Affiliations**: Correct affiliations
- [ ] **Abstract**: Complete and accurate
- [ ] **Keywords**: Relevant keywords

### Final Checks

- [ ] **Compilation**: PDF compiles without errors
- [ ] **References**: All citations resolve
- [ ] **Figures**: All figures display correctly
- [ ] **Page Numbers**: Correct page numbers
- [ ] **Headers/Footers**: Correct headers/footers

## Post-Submission

### Response to Reviews

- [ ] **Address All Comments**: Every reviewer comment addressed
- [ ] **Be Respectful**: Professional tone
- [ ] **Provide Evidence**: Support claims with data
- [ ] **Acknowledge Limitations**: Be honest about limitations

### Camera Ready

- [ ] **Incorporate Feedback**: Address reviewer comments
- [ ] **Final Proofread**: Complete proofread
- [ ] **Format Check**: Final format verification
- [ ] **Supplementary Materials**: Prepare if required
